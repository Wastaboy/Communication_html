What Part 4 builds

TL;DRThe third and final screen, scrDashboard — visible only to the five CCD members. Every request in one place, status filter chips, search, a side panel to update status and notes (which requesters see instantly on My Requests), and the native Excel export.

The steps

D1Screen + CCD gate
  1. New screen → Blank → rename scrDashboard. Copy the header pair again: recDashHeader + lblDashTitle, Text "CCD Dashboard".
  2. In the tree view select App and replace its OnStart with this superset:

App · OnStart (replaces the whole property)

Set(gblEditItem, Blank()); Set(gblShowCancelConfirm, false); Set(gblIsCCD, Lower(User().Email) in ["rawan.alqattan@bbkonline.com", "rafa.kaddoura@bbkonline.com", "abdulrahman.danish@bbkonline.com", "samar.qannati@bbkonline.com", "noora.alfaihani@bbkonline.com"]); Set(gblStatusFilter, "All")
Paste replaces everythingThis formula replaces the whole OnStart — that's why it starts with the two Set lines you first wrote in b3. If you paste a version without them, the submit screen's edit mode and cancel dialog break.
Confirm with CCD / ITThe five addresses above are a guessed format — replace every one with the real address from Outlook before go-live. A wrong address only hides the dashboard button from that person; the data itself is already safe (site Owners see everything, everyone else is fenced by Part 1's item-level permissions). While building, add your own email to the list too — remove it at go-live (e12).
  1. On scrMyRequests add a Button btnGoDashboard: Text "CCD dashboard", X Parent.Width - 488, Y 20, Width 220, Height 48, Visible gblIsCCD, OnSelect Navigate(scrDashboard, ScreenTransition.None).
  2. Run App OnStart once so the variables exist: tree view → App → ⋮ → Run OnStart.
Check before moving onWith your email in the list, the CCD dashboard button shows on My Requests and navigates; with it removed, the button vanishes.

D4The all-requests gallery
  1. Insert → Vertical gallery → rename galAllRequests: X 24, Y 228, Width Parent.Width * 0.5, Height Parent.Height - 252. Items:

galAllRequests · Items

SortByColumns(Filter('Communication Requests', (gblStatusFilter = "All" || Status.Value = gblStatusFilter) && (IsBlank(txtDashSearch.Text) || StartsWith(Title, txtDashSearch.Text))), "Created", SortOrder.Descending)

D6Update panel — notes + save
  1. Text input → txtCCDNotes: X ddStatus.X, Y 296, Width Parent.Width - Self.X - 24, Height 160, Mode TextMode.MultiLine, Default galAllRequests.Selected.'CCD Notes', HintText "Notes the requester will see…".
  2. Button → btnSaveUpdate: Text "Save update", X ddStatus.X, Y 472, Width 220, Height 48, DisplayMode If(IsBlank(galAllRequests.Selected), DisplayMode.Disabled, DisplayMode.Edit). OnSelect:

btnSaveUpdate · OnSelect

Patch('Communication Requests', galAllRequests.Selected, {Status: ddStatus.Selected, 'CCD Notes': txtCCDNotes.Text}); Notify("Request updated.", NotificationType.Success)
Why Patch, not a formPatch writes exactly two columns and nothing else — the requester's own fields can't be clobbered from this screen, and the change appears on their My Requests view at the next refresh.
Check before moving onNo formula errors; button greys out when nothing is selected.

D8Excel export

This one happens in SharePoint, not the app — and that's the point: it's built in.

  1. Open the Communication Requests list in the browser.
  2. Toolbar → Export → Export to Excel; open the downloaded file and click Enable when Excel asks about the data connection.
Filtered exportsFilter the list view first (e.g. Status = Completed) — the export honors the view you're looking at. That plus the Audit Log list export covers FR-7's reporting needs.
Check before moving onThe workbook opens with every request as a refreshable Excel table.
D9Status-names sanity check
Confirm with CCDThe spec left the exact status names open. If CCD wants different ones (say Received / Working / Done), change them in one place — the Status column choices in SharePoint (a3) — then update the three chip Texts (d2) and the c4/d4 Switch color formulas to the same words. Everything else reads the column dynamically.
  1. Ask CCD; if the defaults stand, tick this step and move on.
Check before moving onStatus names are agreed (or consciously left as Submitted / In Progress / Completed).
