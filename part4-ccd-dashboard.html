What Part 4 builds

TL;DRThe third and final screen, scrDashboard — visible only to the five CCD members. Every request in one place, status filter chips, search, and a side panel that now runs the whole workflow: assign a request to a person (Assigned on stamps itself), set its Priority, write CCM notes the requester sees instantly, and mark it Completed — the Completed on/by stamps write themselves too. Plus the native Excel export.

And the centerpiece — one Patch that saves everything the panel edits and writes the workflow stamps by itself:

btnSaveUpdate · OnSelect

Patch('Communication Requests', galAllRequests.Selected, { Status: ddStatus.Selected, Priority: First(cmbPriority.SelectedItems), 'CCM Notes': txtCCMNotes.Text, 'Assigned to': If(IsBlank(cmbAssign.Selected), Blank(), { Claims: "i:0#.f|membership|" & Lower(cmbAssign.Selected.Mail), DisplayName: cmbAssign.Selected.DisplayName, Email: cmbAssign.Selected.Mail, Department: "", JobTitle: "", Picture: "" }), 'Assigned on': If( Lower(cmbAssign.Selected.Mail) <> Lower(galAllRequests.Selected.'Assigned to'.Email), Now(), galAllRequests.Selected.'Assigned on' ), 'Completed on': If(ddStatus.Selected.Value = "Completed", Coalesce(galAllRequests.Selected.'Completed on', Now()) ), 'Completed by': If(ddStatus.Selected.Value = "Completed", If(IsBlank(galAllRequests.Selected.'Completed by'), { Claims: "i:0#.f|membership|" & Lower(User().Email), DisplayName: User().FullName, Email: User().Email, Department: "", JobTitle: "", Picture: "" }, galAllRequests.Selected.'Completed by') ) }); Notify("Request updated.", NotificationType.Success)
What the stamp logic doesFour rules, all in the one formula: Assigned on updates only when the assignee actually changes (re-saving keeps the original stamp). Completed on/by write themselves the first time Status is saved as Completed — Coalesce/IsBlank keep the first completion stamp on later saves. Moving a request out of Completed clears both stamps (the If with no else). And the Claims: record is just how SharePoint wants a person written — the "i:0#.f|membership|" prefix is boilerplate, not something to edit.
Why Patch, not a formPatch writes exactly the workflow columns and nothing else — the requester's own fields can't be clobbered from this screen, and the change appears on their My Requests view at the next refresh.
Check before moving onNo formula errors; button greys out when nothing is selected.
D10F5 test — assign, prioritise, complete
  1. Press F5. Go to My requests, then click CCD dashboard — visible because your email is in the d1 list.
  2. In the gallery, tap the TEST item. The panel preloads: assignee empty, priority empty, current status, current notes.
  3. In the assign combo, search and pick yourself. Set priority to High, the status dropdown to In Progress, and type into the notes box: Reviewing — expect a draft by Thursday
  4. Click Save update — the green "Request updated." banner appears, and the gallery row's meta line now shows High and your name.
  5. Open the SharePoint list in the browser: the item shows Assigned to you and an Assigned on timestamp of right now.
  6. Back in the app, set the status dropdown to Completed → Save update. In SharePoint: Completed on and Completed by filled themselves in.
  7. Set status back to In Progress → Save update. In SharePoint: both Completed stamps cleared — the request is honestly "not completed" again.
  8. Go to My requests and tap the refresh icon: the row's status is navy In Progress, the detail panel shows your note and Priority: High. Press Esc.
Check before moving onAssign stamps Assigned on · Completed stamps and un-stamps itself · the requester's view shows status, note and priority.
D11Excel export

This one happens in SharePoint, not the app — and that's the point: it's built in, nothing to build or maintain.

  1. Open the Communication Requests list in the browser.
  2. In the list toolbar click Export → Export to Excel.
  3. Open the downloaded file and click Enable when Excel asks about the data connection.
Filtered exportsFilter the list view first (e.g. Status = Completed) — the export honors the view you're looking at. That plus the Audit Log list export covers FR-7's reporting needs.
Check before moving onThe workbook opens with every request as a refreshable Excel table.
