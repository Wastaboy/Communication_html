What Part 2 builds

TL;DRThe canvas app itself — Communication Briefing Form — with a submit screen that explains itself: what the form does, why the button is (or isn't) ready, a full confirmation screen after submitting, and a "discard?" safety net so nobody loses typed work. Everything here is spelled out property by property: every amber chip is tap-to-copy, every dark box has a Copy button.

How to set any property

  1. Select the control in the Tree view (left rail).
  2. Open the property dropdown — top-left of the formula bar — and pick the property named in the row (X, Y, Width, Fill, Text, Visible…).
  3. Tap the amber chip or Copy button here, then paste into the formula bar. Paste only the value — never the property's name.
  4. For Text values, the quotes "…" are part of the value. Copy them too.

App · OnStart

Set(gblEditItem, LookUp('Communication Requests', false)); Set(gblShowCancelConfirm, false)
Why LookUp instead of Blank()LookUp('Communication Requests', false) never finds anything, so gblEditItem starts empty — but Power Apps now knows it holds a list item. Initialize it with plain Blank() and the variable has no type, and every formula that asks IsBlank(gblEditItem) shows a red error. Part 3 later sets it to a real item; this line makes both work.

Run it once so the variables exist: App → ⋮ → Run OnStart.

B9Success and failure behavior

Back on scrSubmit: select frmSubmit and set two properties via the property dropdown:

ResetForm(frmSubmit); Navigate(scrDone, ScreenTransition.None)

frmSubmit · OnFailure

Why a screen beats a toastThe confirmation screen stays until the user chooses what's next, and its text answers the "did it work? who saw it? now what?" questions in one read. OnFailure still surfaces the real error if SharePoint rejects the save.

B11F5 test — submit, confirm, cancel
  1. Press F5. With the form empty, read the hint: "Fill the fields marked * to enable Submit." — the button is greyed. No dark overlay anywhere.
  2. Request Subject: TEST from app - delete me later; watch the hint flip to "Ready —…". Pick a Department, type details, pick a date, Attach file → any small file.
  3. Submit request → the confirmation screen: green check, "Request submitted", the what-happens-next text.
  4. Submit another request → an empty form.
  5. Type anything into Request Subject, then Clear form → the discard dialog appears. Keep editing → your text is still there.
  6. Clear form again → Discard → the form is empty. Press Esc.
  7. In the SharePoint list: the submitted item exists, paper-clip icon, Status Submitted.
If submit fails with a permission errorRe-check Part 1: a6 (item-level permissions) and a8 (you're an Owner; staff are Members).
